## 打包和运行

1. `VITE_TEMPORARY_DEMO=true pnpm build` 生成带临时数据提示的前端
2. 从 Node 官网下载 Linux x64 Node 22 的发布包并校验官方 SHA256
3. `node deployment/stage_demo.mjs <node-archive> <node-sha256> <headless-wheel> <wheel-sha256>` 创建独立、全新的白名单打包目录；当前固定 Node 22.23.2、OpenCV Headless 4.11.0.86 的 Linux x64 官方包
4. 在该目录使用 veFaaS 应用部署流程，入口 `python main.py`，端口 8000
5. `demo_boot.py` 在应用导入前设定 production、安全 Cookie、真实模型和临时数据库路径
6. Node 仅监听 127.0.0.1:4173，对外只开放 FastAPI 与 dist；源码、配置及数据路径不可作为静态文件读取

密钥通过平台配置注入，不进入发布包。`DREAMCARD_DEMO_INVITE_CODE` 是单独生成的演示凭据，不复用已有用户邀请码。
`DREAMCARD_CORS_ORIGINS` 必须为部署后的真实 HTTPS 来源。
