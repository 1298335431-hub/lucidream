## 集成边界

此目录是官方联调示例，不能直接当作生产登录服务上线

- 官方资料未明确 `/user` 的稳定账号标识及响应契约，需联调确认后实现账号映射
- 官方资料提示回调可能不返回 state；原始示例允许该情况，但实际应用适配器严格拒绝该回调，不能将其授予真实账号访问权限
- 实际会话有过期、生产环境 Secure Cookie、发起登录的来源检查及错误脱敏；部署前仍需确认公网代理的 Cookie 与日志设置
- 用户授权令牌仅存 Node 进程内存，不能放进前端、URL、数据库或日志
- 不自动合并邀请码历史，不改动每账号 5 次额度，不自动读取梦境并发布至知乎
- 当前内置 Skill 有可选更新，未擅自覆盖官方随包快照

## 本地启动与部署接线

- 原应用：8443；FastAPI：8001；Node 登录适配器：4173，三者同一主机
- 原应用登录页：`http://127.0.0.1:8443/#invite`
- `npm start` 在本目录启动 Node，不能把整个 4173 端口公开
- 在项目根目录启动 FastAPI：`PYTHONPATH=backend .venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8001 --no-access-log`
- 公网 `/api/` 与 `/auth/callback` 转发到 FastAPI，其他页面由前端提供；不能公开示例的 `/api/oauth/*` 或私有 `/api/login/*`
- 公网反向代理也必须对 `/auth/callback` 禁止记录查询串、Cookie 和响应 Set-Cookie
- Node 部署密钥由平台 Secret 注入，不能打入静态资源；FastAPI 不需要取得知乎密钥
- 设置公网域名时同时配置 FastAPI `DREAMCARD_CORS_ORIGINS`，生产环境使用 `DREAMCARD_ENV=production`
- `identityPath` 是平台确认后的 JSON 字段路径数组，不是用户填写的账号信息；测试中的 `data.stable_subject` 完全虚构，不得复制为线上配置
- 两次登录同一知乎身份复用同一本地账户；换登录方式不自动转移旧梦境，请使用原邀请码查看原历史
