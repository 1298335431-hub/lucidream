# 邀请码内测账户

后端默认强制登录。每个新邀请码对应一个独立账户，可重复登录；分享同一码意味着共享账户，不能多人共用。
原前端公开短码已删除，不再有效。新码由管理员签发，数据库只保存摘要。
当前签发格式为 12 位随机字母数字，分成三组（XXXX-XXXX-XXXX），排除 0/O、1/I，登录不区分大小写。新短码通过后端验证，与早期前端硬编码短码无关。

在项目目录执行：

```
PYTHONPATH=backend .venv/bin/python backend/scripts/manage_invites.py --issue 5
PYTHONPATH=backend .venv/bin/python backend/scripts/manage_invites.py --list
PYTHONPATH=backend .venv/bin/python backend/scripts/manage_invites.py --disable ACCOUNT_ID
```

新码仅输出一次，不写日志或前端文件。停用立即阻止所有会话访问，保留记录。
浏览器使用七天有效的 HttpOnly 会话 Cookie；后端保存令牌摘要，支持撤销和过期。
2026-09-15 按用户要求取消登录尝试次数与十五分钟锁定限制；旧 auth_attempts 数据不再参与判断。无效或停用的邀请码仍拒绝登录，来源校验、账号隔离及每个邀请码五次生图额度保持不变。取消该限制后应用不再提供登录猜码限流，正式部署应另行评估防滥用措施。

新梦境创建时原子保存 owner_id，所有梦境、解读、图片及删除接口检查归属。
旧记录 owner_id 为空，仅保留在数据库，不自动分配给任何邀请码。账户历史列表为 GET /api/v1/dreams，最多返回最近一百条；梦境册页面仍需单独接通。
界面偏好仍是浏览器本地设置，不是云端隐私策略。

生产要求 HTTPS、DREAMCARD_ENV=production（启用 Secure Cookie）、前后端同站点。
前端 VITE_API_BASE_URL=/api/v1，生产反向代理将 /api 转给后端，不能用 Vite preview 作为生产服务器。
开发代理同时支持 localhost/127.0.0.1，但请持续使用同一主机名，否则 Cookie 不共享。
生产需配置允许的正式前端 Origin。敏感 API 响应禁止缓存，退出后旧图片地址也需要重新鉴权。

每个邀请码账户累计 5 次生图任务额度，不按月重置。不设置生图频率限制，登录防猜码保护保留。
GET /api/v1/account/quota 返回真实总额度、已用及剩余。账户额度页面已接通，无演示付费方案。
image_quota_usage 按账户、梦境、版本唯一记账，事务串行化防并发超额；启动新任务占用一次，失败也保留占位，同任务重试/核验/用户确认后的补图不再次扣除，修改后新版本是新任务。刷新/下载/文字解读不扣除。删除记录不删除账本，也不返还额度。
质量问题（文字、色带、主体偏差）只提示并展示已有图片，不自动补生成。用户明确确认后最多补生成一次，与故障重试共用一次预算。超时/提交未知仅查询原任务，不盲目重新提交。
image_assets 保留各次图片，image_choices 持久保存选择。版本文件和选择接口均检查梦境归属；补生成失败仍返回原图。已有旧测试图同样可从本地资产恢复展示。
已有邀请码同样适用 5 次，新规则不追扣此前未记账的历史生图。额度和账户随数据库持久保存。
支付、真实历史页面及完整上线配置仍未包含。
自动化测试使用临时库及 mock，不调用模型。测试可显式关闭鉴权；非 test 环境禁止关闭。
