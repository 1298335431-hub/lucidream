# 第三阶段：知识卡审校与生产准入

> 启动日期：2026-09-07  
> 当前范围：只审计75张自建现代简体中文知识卡及生产闸门；不部署上线，不开启云端审核，不修改当前卡片视觉或解读 Prompt。

## 已暂缓、不得遗失的问题

- 图片网络失败或质检失败时，不得在梦卡画面内显示重试提示，避免与标题和解读文字重叠。
- 后续实施时，应将“图片暂未生成成功”与“重新生成图片”固定放在卡片下方操作区。
- 重试只重新生成背景图，不重新生成梦象、解读或排版；请求中按钮禁用并显示“正在重新生成…”。

## 审校顺序

1. **结构完整性**：补齐必填字段，将依据备注转换为可逐项核验的记录。
2. **高风险内容**：优先审校已故亲友、死亡葬礼、怀孕婴儿、裸露、攻击、血与受伤、生病药物、灾害、背叛等卡片。
3. **解读质量**：逐卡检查是否由梦中细节出发，是否保留多种可能，是否避免固定象征和抽象套话。
4. **检索回归**：审校修订后重新编译，运行全部合成检索用例和解读回归测试。
5. **人工签字**：内容审校人和权利审核人留下可追溯记录后，才能评估 `commercial_approved` 与 `production_ready`。

## 本阶段的完成条件

- 75张卡必填字段完整，无 `reviewer` 缺失。
- 高风险卡全部完成语义审校，不包含诊断、预言、吉凶、寿命或治疗承诺。
- 每条事实性表述都能对应到一条可核验依据，并明确权利范围。
- 内容审校与权利审核不能由模型自行宣布通过；未签字前继续保持 `production_eligible=false`。
