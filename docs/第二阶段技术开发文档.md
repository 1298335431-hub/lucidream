## 本轮实际完成

- `TextModerator` 后端适配器，使用阿里云官方 `alibabacloud_green20220302==3.2.4` SDK，业务接口 TextModerationPlus。
- 输入 `llm_query_moderation`（2000字符），输出 `llm_response_moderation`（5000字符）。不截断、不以分块掩盖上下文，超限明确失败。
- 已在梦象提取前、提取结果返回/保存前，以及人工修订保存前设置条件式审核关口；先检查会话存在/状态再审核修订，避免无效请求产生审核费用。
- `none` 才自动通过；low/medium/high 暂停继续，当前没有人工审核队列。此初始保守策略需用合成梦境样本评估误报，特别是暴力梦境、身体感受和传统文化内容，不能把关键词命中等同于用户现实意图。
- 审核开启但凭证缺失、超时、上游错误、未知响应时均不放行。审核失败不调用后续提取模型；修订审核失败不改动原记录。
- 现有本地危机关键词中断保留且先于普通云审核；它是临时保护，不是完整心理危机识别系统。
- 错误仅返回稳定错误码和用户可理解文案，不回显供应商异常、原文、风险词或凭证。无自动重试，避免不受控重复计费。
- 新增 `GET /api/v1/moderation/configuration`，只报告配置存在性，绝不返回密钥或声称真实联通。
- 新增 `python -m app.moderation_smoke`，默认仅看配置；显式 `--live` 才发送两条合成审核请求。
- 后端46项测试通过，其中16项新增审核测试；已下载两份扫描候选素材，详见 `data/knowledge/README.md`。

## 真实状态与边界

## 本地配置待办

1. 用户确认阿里云账号已开通相应服务，以及使用地域。百炼模型Key与审核AccessKey不同。
2. 为专用 RAM 身份配置所需权限，优先最小权限，不使用主账号密钥；如采用临时身份可填写 Security Token。不要在聊天、前端或代码中粘贴密钥。
3. 在本地后端 `.env` 填写以下项（参考 `.env.example`，不要覆盖已有百炼配置）：

```dotenv
DREAMCARD_MODERATION_MODE=aliyun
DREAMCARD_MODERATION_REGION=cn-shanghai
ALIBABA_CLOUD_ACCESS_KEY_ID=本机填写
ALIBABA_CLOUD_ACCESS_KEY_SECRET=本机填写
# 仅使用临时身份时填写
ALIBABA_CLOUD_SECURITY_TOKEN=
DREAMCARD_MODERATION_TIMEOUT_SECONDS=5
```

上海仅为示例，不是用户已确认的地域。当前适配支持北京、上海、杭州、深圳、成都，必须与开通服务匹配，不自动跨地域回退。连接和读取超时各5秒，不是整体工作流总超时。

4. 无远程调用的检查：`PYTHONPATH=backend .venv/bin/python -m app.moderation_smoke`。
5. 用户确认开通/权限与费用后，运行 `PYTHONPATH=backend .venv/bin/python -m app.moderation_smoke --live`。只用合成文本；记录真实结果，失败不要循环重试。
6. 重启本项目8001后端并回归；不动其他项目8000端口，不更改前端UI。

## 正式解读 API（开发态）

- `POST /api/v1/dreams/{session_id}/interpretation`：只接受 `ready_to_generate` 会话。调用链为确认梦象 → 查询扩展 → Embedding → 混合召回 → Rerank → 解读草稿 → 引用校验 → 条件式输出审核。
- `GET /api/v1/dreams/{session_id}/interpretation`：按当前梦境修订恢复已完成结果，或返回未生成、生成中、失败终态。
- 同一 `session_id + revision` 的成功 POST 直接返回落盘结果，不重复调用模型。失败任务不自动重试；只有用户明确触发 `POST .../interpretation?retry=true` 才能从 failed 重新开始。
- SQLite 结构版本为 2，新增 `interpretation_generations`，保存 processing/completed/failed、结果 JSON 和安全错误码。删除梦境会话时一并删除对应解读任务。
- 响应保留书名、作者、译者、词条/章节、原文行号、来源 URL、SHA-256、Rerank 分数、权利与校验状态。当前来源均是候选且云审核未启用，因此强制返回 `production_eligible=false`、`review_status=not_enabled`。
