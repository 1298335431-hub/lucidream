# 架构说明

## 服务边界

```text
浏览器（React）
    │ 同源 /api/v1/*、/auth/callback
    ▼
FastAPI（公开 API、账号校验）
    ├── SQLite：梦境、账号、任务、额度及图片 BLOB
    ├── 模型适配：mock / 阿里云文字与图像模型
    ├── 检索：文献索引 / 自建知识卡
    └── 私有回环 HTTP → Node OAuth 服务（127.0.0.1:4173）
                              └── 知乎授权、换取令牌、读取用户身份
```

本地 Vite 监听 8443，将 API 代理到 FastAPI 8001。云端演示由 FastAPI 同时提供构建后的静态资源，Node 必须与后端处于同一网络命名空间，不可直接作为公开服务暴露。

## 主要模块

| 目录或文件 | 职责 |
| --- | --- |
| `src/App.tsx` | 页面流程、登录状态与主要交互编排 |
| `src/components/` | 梦象确认、梦卡制作、分享准备、账号菜单与向导等组件 |
| `backend/app/main.py` | API 入口与业务请求编排 |
| `backend/app/services/` | 模型适配、文字解读、检索、图片质量、身份验证 |
| `backend/app/storage/` | SQLite 访问与安全快照 |
| `integrations/zhihu-login/lib/login.mjs` | 应用 OAuth 登录状态、授权码交换、稳定身份解析 |
| `deployment/demo_boot.py` | 临时演示运行环境、进程与数据目录初始化 |

## 数据与权限

梦境记录以账号归属校验；修改梦象会产生版本变化，文字与图片任务按记录版本关联。新生图任务占用额度，失败任务的故障重试复用占用，不因删除记录返还额度。

OAuth 密钥只在服务器使用；浏览器不接收 app_key 或知乎用户令牌。后端将经验证的稳定用户身份映射到本地账号，仅向前端提供必要头像和昵称。不要将未验证的浏览器字段用作账号身份。

分享准备在用户界面内完成，原始梦境不会未经选择直接填入发布内容。当前流程是下载、复制、跳转，不调用社区发布 API。

## 数据持久性

本地运行使用 `data/dreamcard.db`。当前云端演示会创建临时数据目录，不接入 TOS，因此服务回收、重启与重新发布可能导致数据丢失。源码仓库不包含线上或本地用户数据库。

正式部署需要重新设计持久卷或数据库、图片存储、迁移和恢复策略；不能通过增加实例数解决 SQLite 与进程内 OAuth 状态的一致性问题。
