# 第二步：阿里云模型适配与真实调用验证

本轮已实现文字和图片适配层，通过 30 项本地测试，随后完成真实 Key 的文字/图片接口冒烟与在线梦象确认链路验证。仍不代表完整解梦链路、60 秒目标或内容审核已通过。第一阶段 UI 未修改。

## 已实现

- 千问 Qwen3.8-Flash 梦象提取：迁入统一适配器，关闭思考与联网搜索，使用 JSON schema 提示和 Pydantic 校验。
- 千问 Qwen3.7-Plus 解读草稿：内部服务，必须传入服务端检索获得的来源片段；引用 ID 和逐字短引文由代码验证。不凭模型记忆补书籍内容。
- 万相 Wan2.7-Image：异步提交、按 task ID 查询；每次只生成一张，不自动重试提交。
- `GET /api/v1/models/configuration`：仅返回配置是否存在，不返回 Key，不执行联网验证。
- 显式真实冒烟命令：只使用合成测试数据，不读取用户保存的梦境。

## 配置与凭证

在项目根目录本地创建 `.env`，参照 `.env.example`。不要覆盖已有文件。Key 只在本机填写，不发送到对话、不写入前端、不提交 Git。

```dotenv
DREAMCARD_MODEL_MODE=aliyun
DASHSCOPE_API_KEY=在本机填写真实Key
DASHSCOPE_API_HOST=https://dashscope.aliyuncs.com
DREAMCARD_QWEN_EXTRACT_MODEL=qwen3.8-flash
DREAMCARD_QWEN_INTERPRET_MODEL=qwen3.7-plus
DREAMCARD_WAN_IMAGE_MODEL=wan2.7-image
DREAMCARD_MODEL_TIMEOUT_SECONDS=20
```

默认 Host 对应北京地域，Key 与地域必须一致。如使用其他地域或业务空间专属 Host，请从百炼控制台复制对应 HTTPS 根地址，不猜测 Workspace ID。当前模型标识是可配置别名，真实验证后再确定生产快照。

从项目根目录运行以下命令，不发起远程调用：

```bash
PYTHONPATH=backend .venv/bin/python -m app.model_smoke
PYTHONPATH=backend .venv/bin/pytest backend/tests -q
```

## 真实冒烟：会消耗阿里云额度

先确认 Key、地域和模型权限，以下命令才会发起真实调用。

```bash
# 两次文字请求：梦象提取结构 + 解读模型连通性
PYTHONPATH=backend .venv/bin/python -m app.model_smoke --live-text

# 提交一次图片任务，记录返回的 task_id
PYTHONPATH=backend .venv/bin/python -m app.model_smoke --live-image

# 查询原任务，不重复生成
PYTHONPATH=backend .venv/bin/python -m app.model_smoke --task-id TASK_ID
```

PENDING/RUNNING 不是失败。SUCCEEDED 且有图片 URL 才表示服务商生成成功，仍须内容审核。任务 URL 有有效期限，并非永久存储。脚本不会将带签名的图片 URL 打印到终端。

后端需要重启才能读取新代码和配置。当前梦卡开发后端使用 8001，勿中断占用 8000 的其他项目。停止本项目旧服务后运行：

```bash
PYTHONPATH=backend .venv/bin/uvicorn app.main:app --host 127.0.0.1 --port 8001
```

## 错误与安全边界

- Key 缺失、模式未启用、鉴权失败、限流、超时、服务异常和返回结构错误均使用固定错误码，不透出服务商原始报错或梦境正文。
- 只接受阿里云 HTTPS 根地址且不跟随重定向。
- 没有来源片段返回 `knowledge_sources_missing`，不继续编造来源。
- 逐字引文匹配不能证明解读合理，语义评测和正式审核仍需补做。
- 画面与风格提示包含确认梦象和风格依据，没有随机风格选择器；最终图像关联度仍待真实验收。
- 单请求 20 秒超时不代表完整链路 60 秒保证。图片提交超时可能已受理，不自动重新提交以免重复计费。
