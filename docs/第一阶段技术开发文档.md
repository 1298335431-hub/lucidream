# 第一阶段技术开发文档｜梦境录入与梦象确认

> 配套文档：《梦卡产品需求文档》《梦卡技术适配声明》《AI Agent 产品 Vibe Coding 通用技术栈手册》V2.1
>
> 本文档只覆盖第一阶段。知识库解读、图片生成和最终卡片下载在后续阶段实现。

## 一、阶段目标

- 用户可以输入一段梦境，也可以通过浏览器原生语音识别补充文本。
- 后端接收梦境文本，创建可恢复的梦境会话，并返回结构化梦象。
- 前端按场景、人物、物件、动作和情绪展示梦象。
- 用户可以编辑或删除梦象，并确认当前修订。
- 每次梦境最多展示一个澄清问题，支持选择“记不清”。
- 页面刷新后恢复最近一次未完成会话。
- 提供可脱离正式前端验证的 API、mock 测试和最小真实模型适配接口。

本阶段明确不做知识库检索、传统资料引用、最终解读、图片生成、卡片下载、登录和云同步。

## 二、技术适配摘要

- 开发路径采用纵向切片。
- 保留现有 React、Vite、TypeScript 和 Tailwind CSS 前端。
- 新增 Python 3.11、FastAPI、Pydantic、SQLite 与 pytest 后端。
- 固定状态机控制流程，模型只负责结构化提取与澄清判断。
- 阿里云通义千问 Qwen3.8-Flash 通过统一适配接口接入；无 Key 时使用显式 mock 模式。
- 本阶段只启用 SQLite，不引入 Chroma、图片模型、对象存储和任务队列。

## 六、数据、资产与状态

### 梦境会话

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `id` | UUID 字符串 | 会话标识 |
| `dream_text` | 文本 | 当前梦境文本 |
| `status` | 枚举 | 当前状态 |
| `symbols_json` | JSON 文本 | 当前梦象结构 |
| `clarification_json` | JSON 文本或空 | 单个澄清问题与选择 |
| `revision` | 整数 | 修订版本，从 1 开始 |
| `created_at` | ISO 时间 | 创建时间 |
| `updated_at` | ISO 时间 | 更新时间 |

本阶段状态为 `draft`、`reviewing_symbols`、`awaiting_clarification`、`ready_to_generate`、`failed`、`safety_interrupted`。

前端 localStorage 只保存最近会话 ID 和未提交草稿。后端 SQLite 是任务与人工确认状态的权威来源。

## 七、API 设计

### `POST /api/v1/dreams/extract`

请求包含 `dream_text`。响应包含会话 ID、状态、修订号、梦象分组和可选澄清问题。

### `GET /api/v1/dreams/{session_id}`

恢复会话。不存在时返回统一 `not_found` 错误。

### `PUT /api/v1/dreams/{session_id}/symbols`

提交用户编辑后的梦象和可选澄清答案。后端增加修订号，状态进入 `ready_to_generate` 或继续等待澄清。

### `DELETE /api/v1/dreams/{session_id}`

清除当前会话。前端必须先提示影响。

统一错误结构如下。

```json
{
  "error": {
    "code": "validation_error",
    "message": "请检查输入后重试"
  }
}
```

## 八、Prompt 设计

Qwen3.8-Flash 只完成结构化提取，不生成解梦内容。输出字段固定为场景、人物、物件、动作、情绪、关系、不确定字段、是否需要澄清和一个澄清问题。

模型输出先经过 JSON 解析，再经过 Pydantic 强校验。格式失败最多重试一次，仍失败返回统一错误并保留用户输入。mock 模式使用确定性规则生成同一响应结构，并在页面明确标注“演示模式”。

## 九、纵向切片界面

第一阶段前端包含三个真实产品状态。

1. 梦境输入页
2. 梦象确认与编辑页
3. 确认完成页，明确提示解读生成将在下一阶段接入

现有落地页中登录、定价、用户评价、永久加密存储、自由风格融合和作品图库不属于本阶段产品事实，应移除或替换。

## 十、测试要求

### mock 自动化测试

- 空文本、超长文本和正常文本
- mock 梦象字段结构与最多一个澄清问题
- 会话创建、恢复、修订和删除
- 非法状态转换与不存在会话
- 损坏 JSON 的安全处理
- 模型异常映射为统一错误

### 真实模型冒烟

- 使用真实 `DASHSCOPE_API_KEY` 调用一次 Qwen3.8-Flash
- 验证首测结构合规率、重试后合规率、耗时和 Token
- 验证日志不包含 Key 和完整梦境文本
- 无 Key 时标记待验，不得以 mock 结果代替

## 十一、验收清单

- [ ] 打开网页后可以输入多行梦境
- [ ] 空输入不会进入下一步
- [ ] 浏览器支持时可以开始和停止语音转写
- [ ] 语音不可用或拒绝权限时仍可使用文字
- [ ] 提交后可以看到分组梦象
- [ ] 可以编辑和删除每个梦象
- [ ] 最多出现一个澄清问题，并可选择“记不清”
- [ ] 确认后修订号增加，页面显示当前结果已按最新梦象保存
- [ ] 刷新页面可以恢复最近会话
- [ ] 清除会话前出现影响提示
- [ ] 后端错误不会展示程序堆栈
- [ ] 页面无明显横向溢出，键盘可以完成主要操作

## 十二、风险与待确认项

- 真实模型冒烟需要用户在本地后端 `.env` 中填写阿里云 Key。
- 浏览器 Web Speech API 的可用性和语言识别质量依赖浏览器，必须保留文字路径。
- 本阶段 mock 提取用于验证流程，不代表真实梦象质量。
- 2026-09-06 产品确认梦境输入上限为 300 个字符；文字输入、语音追加、前端计数和后端校验统一执行该限制。
