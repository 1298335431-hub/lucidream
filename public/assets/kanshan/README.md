# 刘看山网页与梦卡素材

制作页更新：右侧向导固定使用 ball.gif 官方足球动作（原素材名「运球」），生成期间按钮禁用但入场动作正常播放，完成后支持点击重播。等待、生成完成与失败共用同一制作页布局；网页向导仍不写入下载图。

全流程向导（2026-09-15）：新增 sleep.gif（瞌睡，100 帧 / 5 秒）、sway.gif（晃悠，60 帧 / 3 秒）、ball.gif（运球，80 帧 / 4 秒），均从同一官方压缩包原样提取。与 wave、computer、idle 共六种官方动作按页面分配。所有页面向导统一为进入视口先播放一轮，结束后静止 8 秒再播放；等待时点击立即播放，结束后重新计时 8 秒，播放中重复点击不打断、不排队。离开视口暂停，重新进入先播放；尊重减少动态效果，离开页面清理动画与计时。制作页生成期间仍禁用两侧按钮，但向导自动播放与 8 秒间隔正常运行。短气泡为产品操作提示，不代表知乎官方解读或发布结果。向导与气泡位于导出区域之外，下载文件仍只有可关闭的静态小看山标识。

静态梦卡标识（2026-09-15）：idle-static.png 由 idle.gif 首帧转换为透明 PNG，保留原始 320×320 画布与官方形象，没有改绘。用于梦卡左下角替代「梦卡」文字，显示尺寸 44×44，可在「画面调整」中关闭；沿用 showLabel 偏好。预览、下载和分享预览遵循同一个开关。下述 GIF 动画仍仅用于网页，不写入梦卡；本段静态标识是例外。左上角 LUCIDREAM 标识保持不变。

来源：用户提供的《知乎黑客松 2026｜校园新锐季 开发者手册》附件「刘看山动态.zip」中的「待机_5秒_320x320_20fps_透明.gif」。idle.gif 为原始文件拷贝，未改绘。

wave.gif 来源于同包「打招呼_4秒_320x320_20fps_透明.gif」，同样保留官方原始文件。

computer.gif 来源于同包「电脑_6秒_320x320_20fps_透明.gif」，保留官方原始文件，包含坐着敲电脑及起身动作。

用途：网页导航恢复原有 DreamCardLogo，刘看山仅作为首页输入框左上沿的向导。首次进入或刷新后，素材就绪即播放一轮 computer.gif（120 帧，每帧 50 毫秒，共 6 秒）；播放结束后静止 8 秒，再播放一轮。等待时点击立即播放并聚焦输入框；播放中重复点击不打断、不排队。素材每次页面加载只下载一次，每轮用新的本地对象 URL 从头播放，结束时释放。切换到后台停止，回到前台重新等待；组件卸载会清理计时与请求。系统开启减少动态效果时仅显示静态首帧。不会用于生成或下载的梦卡。

手册限制：赛事期间使用；赛后商用需另行联系知乎取得授权。使用该素材不代表产品由知乎官方运营。

分享介绍区：样卡上沿使用官方 wave.gif（80 帧，每帧 50 毫秒，共 4 秒），进入视口即播放，结束后静止 8 秒；可点击再次播放。离开视口后停止并清理计时，减少动态效果设置下保持静态。该向导位于网页层，不写入样卡图片或下载文件。
